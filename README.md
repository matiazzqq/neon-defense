## 🎯 О игре

**NEON DEFENSE** — это браузерная стратегия в жанре Tower Defense, написанная на чистом JavaScript и HTML5 Canvas. Тебе предстоит защищать свою базу от бесконечных волн врагов, используя четыре уникальных типа башен.

Игра работает полностью в браузере: ничего скачивать не нужно. Отлично подходит как для ПК (мышь + клавиатура), так и для мобильных устройств (сенсорное управление).

### ✨ Ключевые особенности

- 🏗 **4 типа башен**:
  - 🔫 **Пулемёт**: Быстрая стрельба, низкий урон. Идеален против мелких врагов.
  - ⚡ **Лазер**: Постоянный луч, высокий DPS. Пробивает броню танков.
  - 🚀 **Ракета**: Урон по площади (AoE). Незаменим против толпы.
  - ❄️ **Заморозка**: Замедляет врагов. Комбо с другими башнями уничтожает всё.
- 👾 **Динамические волны**: Враги становятся сильнее с каждой волной.
- 💀 **Боссы**: Каждые 5 волн появляется огромный босс с тонной здоровья.
- ⬆️ **Прокачка**: Каждая башня улучшается до 3 уровня, становясь мощнее.
- 💰 **Экономика**: Зарабатывай деньги за убийства и продавай ненужные башни.
- 📱 **Мобильная версия**: Полная поддержка тач-управления.

## 🕹 Как играть

1. Нажми кнопку **"ИГРАТЬ"**.
2. Внизу экрана выбери тип башни (или нажми цифры `1`, `2`, `3`, `4`).
3. Кликни по свободной клетке на карте, чтобы построить защиту.
   - *Зелёный квадрат* = можно строить.
   - *Красный квадрат* = нельзя (путь или занято).
4. Нажми **"▶ Начать волну"**, когда будешь готов.
5. Кликай по уже построенным башням, чтобы **улучшить** или **продать** их.
6. Не дай врагам дойти до красного дома справа! Если жизни закончатся — Game Over.
